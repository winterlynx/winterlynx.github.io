# 晴冬



转眼1月已经过完。节前3,4天前还一直挺忙。春节的时候，突发奇想 想背点单词。因为平时的时间并不总很稳定，春节大概已经是我仅有的假期了。当然我也做不来那种一个长假背完整本红宝书的事情。至少有每天坚持，假期里一共背了1500。到后面稍微习惯些，背的速度也有加快，但需要复习的内容也越来越多。。到结束为止，似乎还能记得住90%-95%（本来就算不接着背也应该要保存一段时间的复习的，但是实际重新上班之后就没做这事了：P）。背单词对我还有点枯燥，不过从词根词源中有时候也能发现点乐子。比如venial的词源和维纳斯有关，意思则是“当然是原谅她拉”（笑死，实际意思是可原谅的）春节期间大体做了这事。其他的东西倒是也学一点，不过因为时间不好掌握，就随着心情来。不看任何材料推些东西，感觉还可以。因为我似乎没有新冠的症状，所以也不确定自己得没得过，搞得挺不敢出门，既没去看电影，也没有去植物园。原本冬日走在太阳下，是我们这一年最舒服的时候。既不担心冷，也不容易流汗。初三的时候去了次本地的博物馆，里头刚好有两个小展，沈阳故宫博物院的后宫生活以及明朝益庄王墓。回家的时候已经是中午1点多。阳光暖暖地照在身上，要不是肚子饿了，真想在旁边公园的草地上躺上一躺。


今年的鞭炮烟花总觉得比往年更嘈杂一些，听说一些原本禁止燃放的区域今年也都默许。我早已过了喜欢这些的年级，只觉得时长吵得没法睡觉或者听不清视频里的声音。烟花则多是个人购买的小型款式，绽放出得形状千篇一律。想起初中那会，有天市政府不知啥缘由，突然花大价钱买了烟花给市民看。绽放开来是各种花朵的，灯笼的，蝴蝶的，变换颜色的，一层层展开变得像画的……只觉得各种设计确实非常有新意，不过也因为见识过那种阵仗，之后普通人家放的小型烟花就完全提不起兴趣来了。日本动画中常有和喜欢的人一起逛庙会看烟火，想来确实很不错，不过还没有体验过。春节期间家里和亲戚确实还有催，但比起前两年没有那么难熬了。我也知道母亲属于烦恼藏在心里的类型，不说出来自有很多烦恼。不过最近这段时间这事实在没啥眉目。说起来整个21年我连个新朋友都没有认识。心思都在学习上倒是不太想这方面的事情。连豆瓣都上得少了。老实说，即使是现在也常常感慨早年认识的豆瓣朋友每个人真的都非常优秀。这几年则非常不行，不是说就没有优秀的人，但是比例真是完全不同。春节这段时间，因为背单词，时常回忆起没有网络的时代坐在书桌前的日子。那时候县城里能买到的书也有限，时常就没有东西可读。读字典，辞海也是常有的事。背单词的时候也时常想要是还能有读英语词典的时间就好了。小学时候几个小伙伴聚在一起却不知道玩什么的无聊时光也常有。回想起来除去红白机或者动画带出来的娱乐活动，有不少周末娱乐都是我带出来的。我记得有一次是自己按照科技书做了个飞碟。然后是燕子飞机，回旋镖，折各种各样的纸船。斜坡跑步小人，恐龙印章，看恐龙书，观察蚂蚁……春节假期尽量减少了网络使用。网络对我来说，始终是有巨大好处的。那时候总幻想着能看到买到很多很多的书。能学到不同的知识，认识有不同兴趣爱好的人，见识他们的生活。这些无疑在网络的发展中早已实现。然而现在的网络所“给与”的远不止这些。但我想要的其实始终只有那么多而已。更多的输入渐渐占用我们的时间。甚至让人忘记自己原本想要的，比如现在很多人已经不看书了（当然也不是人人想看书）。我觉得一个人的自我其实是由他怎么使用每一天每一点时间定义的。自己想象中的自我，和通过行动塑造的自我往往有很大差异。回归原本的生活还是挺惬意的，现在真的有读不完的书，也有很多可以思考的事情。唯一缺的大概就是时间了吧。也会想象着在幽静的山中的庭院里，这样度过每一天。


节后马上就是连上7天班。好在年后的工作暂时还不算多。这段时间的专注力都非常不错（其实距离开工也才5天啦），从这种专注和学习状态中能自然地感觉到愉悦。看来12月的时候专注力变差还是工作上的压力与焦虑导致的。要是一整年都能是这个工作量和专注力就好了，虽然不可能。最近即使下班偶尔想放松下，也觉得游戏没什么意思，还不如解围棋死活题有趣。于是又有点想学围棋，大概算是周期性欲望了吧：P每天留两题在手机里，累了的时候想想倒还是不错的。


最近天气晴好，白天是挺好的，到了夜晚气温会降到很低。同时皮肤也能感受到干燥带来的影响。但是即使是这种天气，我们这的湿度也是比北方的常态要高的吧。连这种湿度都能体会到影响，不知道面对北方的天气会怎么样。。


暂时写这么多吧。
