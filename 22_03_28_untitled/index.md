# 七天无休上班中



转眼又过了一个月。初想起来似乎都和上个月差不多，没什么值得写的。试着以每周为单位稍微回忆了一下，还是做了不少事的。不过总不至于把每周学了什么算了什么都一一列出来（虽然这样其实应该还蛮有成就感的，但是也很花时间）


二月底和3月初的两周，气温一下升得很高，最高气温全是一票的29-30，直接穿短袖也没问题，偶尔在出太阳的时候在走廊摸鱼，空气中似乎隐约能闻到爆嗮过后的空气味儿，有时候还有爆嗮之后的龙眼味。最近因为晒太阳，发展出了新型的摸鱼方式——打印几页书，找个没人的角落站着看。站着摸鱼有很多好处，首先远离电脑手机专注力好。其次可以选择一些空气流通好的地方（其实去户外且有桌椅更好，不过摸鱼都能摸到户外去就有点厉害了），还能晒太阳。想起小时候没零花钱在书店站着看书的周日下午。记得那时候站上一段时间，脖子和腿都有点酸。这几天摸下来倒是完全没感觉。大概摸鱼时长不够。也可能因为锻炼之后核心力量略有加强。气温升上30度之后，这种兼顾晒太阳的摸鱼方式就显得没有很适宜了。
<!--more-->

24日周四，终于通关了健身环，一共花了10个月整。虽然健身环有一堆缺点，但是就实际效果来看，让我坚持锻炼了10个月，不仅瘦身，也带来了以前讲过的一系列好处。所以还是非常感谢这个游戏的。单位的人时不时就会有人问我是怎么瘦回来的，因为像我这样能在快速瘦回来的人很少见（在我自己的经验范围内似乎也没有）。通关之后虽然还有第二世界，但是目前来说总感觉第一大关即简单量又特别少。而且大boss没有了，多少还是有点无趣。


3月中旬，疫情突然变得严重起来。于是类似于去年9月，又开始全员无休一周7天的上班模式。目前已经持续到第三周，因为周边县还持续地有新增，所以这种日子估计还要持续3-4周以上。少了周末的缓存，感觉真的挺累的。这几天明显感觉到一天的精力不如前段时间。而且工作还蛮多的，连周末都不得闲。然后因为有些考评从按年评比变成按季度评比，突然间就又多了很多事。大体上3月的第一个星期还可以，到了月底就完全没空摸鱼了。清明的假期已经确定没有了，51怎么样还不一定。说到51有点想念以前扫墓时走过的山间小路，阳光明晃晃地，路旁长着很多大蓟，山脊附近的山坡上是成片的蕨类……喜欢那种色彩鲜艳的田园感。可惜后来修路有了稍微好些的其他路线，就再没走过那条路了。在内楼道（比较没人）边缘的走廊摸鱼，偶尔能听到墙对面的市场有人在放闽南语歌曲，也会想起曾经寒假里在奶奶家醒来的早晨。当初不太喜欢这些歌曲，如今听起来也时常有些感慨……


最近偶尔看网上的科普文，遇到新知识总有点怀疑想自己确认一下。真的这么做的话就觉得科普文的坑实在太多了。但是每个都自己验证就觉得很累，也没有时间。就像鱼说的如果有时间肯定是自己读第一手的文献最靠谱。因为这个原因有时候会觉得学物理比起学数学自由很多。其实感觉自己应该也比较适合物理，能把自己知道的东西，灵活运用到其他很多地方，大概像费曼那样。现在的我自然也有能力做这种事，但是数学毕竟是学不完的，时间总也不够。


之前看到有个视频讲王守仁的知行合一。说世界上并没有什么知行不合一，所有的知行不一，本质都是你以为你知道，但是实际上你并不真正知道。感觉还蛮有道理的。


大概就写这么多吧，原本4月打算到五缘湾找栗喉蜂虎，目前这疫情看起来非常难，而且我也实在太累了，想有个假期能好好休息下。
