# 冷雨



最近工作之余的时间基本都在学习，效率还蛮高的。因为也没发生什么其他事，所以就有点懒得写博文。


18日开始下雨。没有冷锋过境狂风大作的阵仗，只是安静地下着细雨，转眼之间气温就降到4度左右。原本4度就算在我们这也算不上最低温，但配合着雨水的湿气，就有种所有东西都热不起来的感觉。被窝里像是冰窖。这周工作莫名开始多起来，连着几天上班都没机会摸鱼。


今年的春节长假大概是效率最高的假期，虽然在家里很容易被说话声或者电话影响，效率肯定没有自个在宿舍的时候高，但对比往年的自己还是很不错的。身体上感受不到节日的异样，一整天除去吃饭和帮忙洗菜就全都在学习。以前我是那种脑子里不断地有新想法冒出来的类型，很多的想法。这段时间这种想法少了很多。自己能全身心地沉浸在当下的时间和空间里。感受听起来和那些做冥想的人的描述有点像，不知道是不是真的一样，大概是湍流和层流的的区别。感觉大脑形成一个整体在工作。然后数学方面感觉自己也有进步，之前说觉得比起学习别人的想法更喜欢自己重新创作出这些知识，感觉目前似乎有点能做到这一点，在领域内到处探索，也能体会到自己可以到任何地方的爽快感，比在现实中到处走要有趣。有时候发现自己思考过的问题，正好是书里的下一节或下一段，用的还正好是自己想的方法，就特别有成就感~周末不吃午饭想问题，整个过程肚子咕噜咕噜叫，在2点半的时候解决了什么的感觉也很满足。


然后不满意的地方主要还是一天的时间如今对我来说还是非常不够，哪怕周末自己一个人在宿舍。没有人打扰，但是做饭吃饭洗衣服一些琐碎的事情占用的时间比想象中多。当然我实际上也做不到一整天不停顿的学习就是了。中间怎么放松和恢复也算是个问题。有时候想到户外呼吸下新鲜空气应该就挺不错，不过目前还找不到方便的地方。想有个大桌子，能把书和草稿纸随意铺开，最近挺想远离电脑。然后是目前在看的英文闲书都是epub版的，epub排版比较好，但是在手机上，boox或者电脑上显示的页数都不一样就挺不好规划进度的，连自己一天看了几页都不好统计= =


这个月里看了丘成桐的传记，然后看别人经历就特别想顺道看看八字什么的。加上因为尚西的儿子是建禄格，所以她找我聊了点这方面的事情。于是顺带搜了不少数学物理方面名人的八字。发现绝多数人从事学术的人都是官印相关的体系或用印的。然后也有另一派数量少得多的是用财的。丘就是用财的。当然还有一些更奇特的人，比如黎曼，似乎既不属于用印也不属于用财。单一个食神制杀，所有的八字组合起来感觉像是一个永动机一样，从恶魔那里源源不断地榨取宇宙的秘密（当然八字看也不是真的永动机，食神其实是损耗的）。看到有说法说食神制杀啥都好就是容易短命。看了那么多名人的八字，就觉得八字确实还是挺有道理的。如果有足够的数据，早夭其实完全可以用科学方法做研究，毕竟死亡是挺确定的事情。


就写这么多吧，感觉有时间还是学习就好，没什么想说的话。
