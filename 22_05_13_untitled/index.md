# 忙碌季



4月9日在持续上了一个月班之后终于重新开始放假。不过那之后的一段时间感觉自己状态还是有点没恢复。有空的时候虽然照旧学习，但是专注力就明显不如年初的时候。51休息了一下，似乎有所恢复。但是工作上3,4个事情一起来，突然就又变得异常忙碌。有时候要连着加班，有时候是整个上班时间一口水都没机会喝。也有好几天需要我楼上楼下到处跑做协调。运动手表显示那几天每天的走路步数都超过10000，爬楼高度是200+米，大概爬了有65-70层楼那么高。不过手表的爬楼只算上楼不算下楼，所以实际上下楼也有那么多。前几天突然就感觉膝盖的半月板有点异样。好在后来没有持续的异样感。。这种状态下完全没有摸鱼的空间，并且下班之后感觉人也很累。这周有两天都是晚上8-9点就睡。睡足8小时的第二天倒是精神异常的好。忙一天下来，直到凌晨3-4点很还很有精神。但是这就导致接下来的一天睡眠有点不足orz总之这近一个月的时间里学习的效率并不是很高。


如果持续忙碌下去在考虑是不是要每天8点睡，然后凌晨3点起。中间试了一次。感觉早起的状态还是相当好的。感觉人的专注力还是和心中的杂念息息相关。早晨是人一天中最空的时刻。以前和zephyr提到过我关于梦的猜想。梦可能是白天未平复的兴奋的神经元组合成的结果。人在一天的活动中总是在被各种外界或者内部信息打断着的。一些信息可能处理了一半，就被中断了，转而处理其他信息。这些中断的过程，有些可能会被重新捡起，有些可能就被我们遗忘了。但是与这些处理相关的神经元可能还是处在兴奋状态的。到了一天的结束阶段，这些还在处在兴奋状态的神经元作为信号源和大脑未休息的部分混合在一起可能就产生了梦。从这个想法出发，人一天的杂念是持续增多的似乎也很好理解。之前在豆瓣上看到，有人通过冥想，达到去除杂念的效果。这种状态我在1,2月份似乎也有达到过。4月份则不太行，感觉内心的杂念多了很多。不知道是不是也可能尝试着做冥想，但是每天再花一小时做这个其实也很难呢。如果将来有空确实是可以尝试下的事情。其实这个世界上有很多事情都是必须自己试了才知道的。多数事情内的是非好坏酸甜苦辣，都不是一句话能说清楚的。


51的时候把万人臭骂的无职动画版看完了。上半季没什么出彩的点，下半季里则有两个小段落我还挺喜欢的：归乡篇主角经历困苦从险恶的魔大陆归来，见到父亲原本有点自豪，想向自己的父亲炫耀一下。然而父亲这边因为失踪的不止主角一人，自己的妻子和女儿也都还下落不明。两个人因为立场不同而产生的冲突。我觉得这种刻画还是相当不错的。另一个我很喜欢的小段落是男主的老师洛琦希所在的村落，所有村民天生带有念话能力。可以在不发出声音的前提下彼此沟通。而洛琦希从出生就没有这种能力。她没法知道其他人在说什么，成长于这样的环境下让她一直很痛苦，疏离感最终让她选择永远离开这个村庄。然而同样感到痛苦的还有她的父母。母亲会因为把孩子生得和别人不一样而感到自责。她理解自己孩子的痛苦，也理解孩子选择离开的决定。而且母亲同样有对孩子的思念。所以洛琦希回村庄的时候，母亲说至少每20年回来一次看看我们好不好。这个地方也挺让我感动。也不知道是不是受到这段的影响，51假期快结束的时候离开家的时候也有点别样的情绪。也想和母亲表达些什么。但是我们家一直以来其实确实有点缺乏表达爱的手段。母亲节大概是有表达一下的。虽然感觉还是不善于此……


先写这么多吧，工作上的事太多，也没有太多其他的想法……
